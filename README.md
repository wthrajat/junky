# Junky

Just works. An extremely light junk cleaner for Windows.

[Download for Windows](https://github.com/wthrajat/junky/releases/latest)

## Download

* Get **`junky-gui.exe`** from the [latest release](https://github.com/wthrajat/junky/releases/latest).
* Run it. No installer. Admin rights unlock system locations.

## What it does

* Scans first. You see everything before anything is deleted.
* Cleans known junk locations. Skips locked files.
* Optional deep clean stays off unless you turn it on.

## Command line

```console
junky scan
junky clean --yes
```
